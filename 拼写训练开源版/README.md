# 拼写训练

一个无需安装的本地拼写练习网页：通过主动回忆、拼写分块、即时纠错与复习，让练习结果可见。

## 使用

双击 index.html，或部署为静态网站。选择词表，使用顺序、倒序、随机、学习或复习模式。填写的姓名仅用于学习记录截图，可使用昵称。

点击“加载新词表”导入 JSON、CSV 或制表符分隔的 TXT/TSV。JSON 示例见 examples/示例词表.json；CSV 表头为 word,meaning,group,phonetic,syllables,note。稳定且唯一的词条 id 可用于更新词表，避免重复添加。

音节提示是简化的拼写分块规则，不保证与真实发音边界一致。词表可用 syllables 字段提供人工划分。读音依赖浏览器与设备的语音支持。

## 数据与隐私

本版只内置八个通用示例，不含学生个人词表、教学文档或完整第三方词库。姓名、导入词表、作答和进度保存在当前浏览器 localStorage 中，没有云端账户同步。更换网址、浏览器或清理存储可能导致记录不可用，请先导出备份。备份可能包含个人信息，请勿提交到公开仓库。

## 统计

首次独立作答、复习和辅助练习分别统计；同题重试不重复计分。每日以设备当地时间凌晨4点切换。练习达标不等于长期记忆保证。

## 发布

index.html 可作为 GitHub Pages 入口，无需构建。只上传本目录；不要附带教学版、个人备份或学生资料。
